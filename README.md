* **핵심 내용:** 사용자의 발표 영상 및 음성을 분석하여 실시간 피드백을 제공하는 지능형 시스템
* **주요 기능:** * Retrofit을 활용한 서버 통신 및 분석 데이터 처리

    * 발표 스크립트 기반 AI 챗봇 및 분석 결과 시각화(Donut Chart 등)
* **핵심 스택:** `Kotlin`, `Android`, `Retrofit2`, `Firebase`, `AI Analysis`
* **링크:** [GitHub Repository 바로가기](https://github.com/minyook/capstonedesign)
